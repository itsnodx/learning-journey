# Journal des séances réseau

Ce dossier regroupe une note par séance d'apprentissage. Chaque note distingue **le concept**, **les observations**, **les exercices réalisés** et **les prochaines vérifications**.

## Convention de nommage

`AAAA-MM-JJ-seance-NN-sujet.md`

Exemple : `2026-11-06-seance-01-osi-tcpip.md` (nom illustratif uniquement ; la date doit correspondre à la séance réelle).

## Modèle de note

```md
# Séance NN — Sujet
Date : AAAA-MM-JJ
Module : 01 — Fondamentaux des réseaux

## Objectif
## Concepts compris
## Observations et essais réalisés
## Questions et erreurs
## Ce que je retiens
## Prochaine séance
```

Les travaux pratiques complets, avec topologie, commandes, captures et configurations, sont publiés dans [NodX-Lab](https://github.com/itsnodx/NodX-Lab) **uniquement une fois réalisés et vérifiés**.
